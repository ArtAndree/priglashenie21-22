# Полное приглашение на юбилей

21–22 ноября 2026 года. Гостевой дом «Чайковский», Казань, ул. Дементьева, 51.

## Открыть
Откройте index.html. Изображения и анимации встроены. Сборка и установка не нужны. Шрифты загружаются из Google Fonts; без сети используются запасные шрифты.

## Разместить на GitHub Pages
1. Загрузите index.html, README.md и .nojekyll в корень репозитория. Загружайте распакованные файлы, а не архив.
2. В Settings → Pages выберите Deploy from a branch, main, / (root), затем Save.
3. Дождитесь ссылки в разделе Pages. Публичный сайт будет доступен всем по ссылке.

## Возможности
- Приветствие персонажа с подъёмом бокала и отдельными движениями головы и руки.
- Нажатие на персонажа: тост, новая реплика и праздничные частицы.
- Повтор приветствия и кнопка пропуска.
- Маршрут в Яндекс Картах, копирование адреса, календарь на два дня.
- Крупный текст, закреплённые кнопки на телефоне, учёт нижней безопасной зоны экрана.
- Настройка уменьшения движения устройства отключает анимацию.
